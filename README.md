A multiplayer 3D vehicle racing and survival game developed using **Unity and Photon PUN (Photon Unity Networking)**.

Inspired by GTA V's Sumo and Parkour racing modes, this project focuses on competitive multiplayer gameplay, vehicle-based challenges, and online player interactions.

The game combines vehicle customization, multiplayer lobbies, and challenging racing environments into a competitive experience.

## 🎮 Game Overview

Players compete against each other in multiplayer vehicle challenges inspired by two popular gameplay styles:

- **Sumo Mode:** Vehicle-based survival challenges where players compete to outlast their opponents.
- **Parkour Racing:** Navigate challenging tracks, obstacles, and platforms while competing against other players.

The game is designed around simple multiplayer matchmaking and accessible vehicle controls.

## ✨ Key Features

### 🚗 Vehicle Selection & Customization
- Select a vehicle before entering gameplay.
- Customize the selected vehicle's color.
- Personalize the vehicle before competing against other players.

### 🌐 Multiplayer Gameplay
- Multiplayer functionality developed using **Photon PUN**.
- Lobby-based multiplayer sessions.
- View the number of players currently present in the lobby.
- Compete with other players in online vehicle challenges.

### 🏁 Competitive Game Modes
- Sumo-style vehicle challenges.
- Parkour-inspired racing tracks.
- Multiplayer-focused competitive gameplay.

## 🎮 How to Play

1. Download the available game build from this repository.
2. Extract the files if the build is provided as an archive.
3. Launch the game executable.
4. Select your preferred vehicle.
5. Customize your vehicle color.
6. Enter the multiplayer lobby and check the current player count.
7. Join the available multiplayer session and compete with other players.

**Note:** Online multiplayer functionality requires an internet connection and an operational Photon networking service.
